LabelBench — one more step

set up this workstation

The server is reachable. This workstation just does not trust the certificate the server presents, so the browser will warn — and, more importantly, the page will not be a secure origin, which means the browser will not let it reach a printer.

Two steps: trust the certificate, then open the app over HTTPS.

1 — Fetch the certificate

The root certificate of the lab's internal CA. Its fingerprint is:

F4:E5:16:F1:25:B8:19:14:0B:96:9F:AC:A0:E8:D3:BD:1C:95:7E:DF:85:58:DA:60:64:4A:8A:78:41:13:9E:55

Download rootCA.pem — or in a terminal:

curl -O http://{{ placeholder "env.LABELBENCH_HOST" }}:{{ placeholder "env.LABELBENCH_HTTP_PORT" }}/rootCA.pem
openssl x509 -in rootCA.pem -noout -fingerprint -sha256

Check the fingerprint against the line above before you install it.

2 — Trust it

Linux

sudo cp rootCA.pem /usr/local/share/ca-certificates/labelbench-rootCA.crt
sudo update-ca-certificates

Windows (PowerShell, as administrator)

certutil -addstore -f "ROOT" rootCA.pem

macOS

sudo security add-trusted-cert -d -r trustRoot \
  -k /Library/Keychains/System.keychain rootCA.pem

Restart the browser afterwards — it reads the trust store when it starts.

3 — Open the app

By address — this always works, whatever the network:

https://{{ placeholder "env.LABELBENCH_IP" }}:{{ placeholder "env.LABELBENCH_HTTPS_PORT" }}/

By name — works when the name resolves on this network:

https://{{ placeholder "env.LABELBENCH_HOST" }}:{{ placeholder "env.LABELBENCH_HTTPS_PORT" }}/

If the name does not resolve, add it to the hosts file (C:\Windows\System32\drivers\etc\hosts on Windows, /etc/hosts elsewhere):

{{ placeholder "env.LABELBENCH_IP" }} {{ placeholder "env.LABELBENCH_HOST" }}

Open LabelBench

LabelBench — a self-hosted label design app. The printer must be plugged into the workstation the browser runs on; the server never talks to a printer.
